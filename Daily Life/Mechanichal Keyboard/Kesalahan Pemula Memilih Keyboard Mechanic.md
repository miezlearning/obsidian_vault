1. **Switch Tidak Sesuai Ekspektasi**  
   - **Masalah**: Banyak pemula bingung memilih switch (misalnya, Red, Brown, Blue) karena tidak tahu perbedaan rasa dan suara. Misalnya, kamu bilang Red terasa "terlalu crispy" (mungkin maksudmu terlalu ringan atau kurang umpan balik). Switch Red (linear) memang halus dan ringan (45g), tapi kurang tactile (tidak ada "bump"), sehingga bisa terasa kurang memuaskan untuk mengetik.
   - **Contoh**: Seseorang membeli keyboard dengan Blue switch untuk kantor, tapi ternyata terlalu berisik, mengganggu rekan kerja.
   - **Solusi**: Coba switch tester (alat kecil dengan beberapa switch untuk dites, harganya sekitar $10-20) atau baca ulasan di YouTube (misalnya, “Switch and Click”). Untukmu, Brown switch mungkin lebih cocok karena tactile (ada bump) dan lebih seimbang untuk mengetik/gaming.

2. **Kualitas Keycaps Buruk**  
   - **Masalah**: Keyboard murah sering pakai keycaps ABS tipis yang licin setelah beberapa bulan (shiny) atau tulisannya cepat pudar. Pemula sering tidak tahu perbedaan ABS vs. PBT.
   - **Contoh**: Keycaps ABS pada keyboard gaming murah terasa licin setelah 3 bulan, membuat mengetik tidak nyaman.
   - **Solusi**: Pilih keyboard dengan keycaps PBT (lebih tahan lama, tekstur kasar, suara lebih dalam). Alternatifnya, beli keyboard hot-swappable agar bisa ganti keycaps nanti.

3. **Stabilizer Bermasalah (Rattle)**  
   - **Masalah**: Tombol besar (Spacebar, Enter) sering berbunyi "rattle" (goyang atau berisik) karena stabilizer tidak dilumasi dengan baik. Ini umum di keyboard pre-built murah.
   - **Contoh**: Spacebar terasa goyang dan bunyinya mengganggu saat mengetik cepat.
   - **Solusi**: Pilih keyboard dengan stabilizer yang sudah dilumasi (pre-lubed) atau belajar melumasi sendiri (tutorial di YouTube seperti Taeha Types). Keyboard seperti Keychron Q-series sering punya stabilizer lebih baik.

4. **Build Quality Lemah**  
   - **Masalah**: Keyboard murah (biasanya plastik tipis) terasa ringkih, berderit, atau tidak stabil di meja. Case plastik murah juga bisa memengaruhi suara (kurang “thocky”).
   - **Contoh**: Keyboard gaming di bawah $50 sering terasa “hollow” (kopong) saat diketik.
   - **Solusi**: Cari keyboard dengan case aluminium atau plastik tebal untuk build quality lebih baik. Keychron V-series atau NuPhy Air75 adalah contoh terjangkau dengan build solid.

5. **Kompatibilitas dan Software**  
   - **Masalah**: Beberapa keyboard punya software kustomisasi (untuk RGB atau remap tombol) yang sulit digunakan atau tidak kompatibel dengan macOS/Linux. Pemula sering kesulitan mengatur layout.
   - **Contoh**: Software Razer Synapse tidak berjalan mulus di Linux, membuat pengguna kesulitan mengatur RGB.
   - **Solusi**: Pilih keyboard yang support VIA/QMK (software open-source untuk kustomisasi) atau punya software sederhana seperti Keychron Engine. Pastikan kompatibel dengan OS yang kamu gunakan.

6. **Harga Tidak Sebanding dengan Kualitas**  
   - **Masalah**: Pemula sering tergiur keyboard gaming murah (<$50) dari merek tidak terkenal, tapi kualitasnya mengecewakan (switch jelek, keycaps tipis, stabilizer buruk).
   - **Contoh**: Keyboard “RGB gaming” di e-commerce sering overpromise fitur, tapi build quality buruk.
   - **Solusi**: Investasi di keyboard terpercaya seharga $70-120 (misalnya, Keychron V5 Max, NuPhy Gem80) untuk kualitas yang lebih baik dan fitur seperti hot-swappable.

7. **Kurva Belajar untuk Kustomisasi**  
   - **Masalah**: Pemula yang ingin kustomisasi (ganti switch, keycaps, atau lubing) sering bingung karena butuh alat (solder, puller) dan pengetahuan teknis.
   - **Contoh**: Seseorang mencoba ganti switch tanpa puller, akhirnya merusak PCB.
   - **Solusi**: Mulai dengan keyboard hot-swappable (tidak perlu solder) dan tonton tutorial dasar di YouTube. Beli alat dasar seperti keycap puller dan switch puller (harganya murah, ~$5-10).

### Hal yang Harus Diperhatikan Sebagai Pemula Saat Membeli Mechanical Keyboard
Berdasarkan kendala di atas dan preferensimu (menghindari switch Red yang “crispy”), berikut panduan untuk memilih keyboard pertama yang aman dan cocok untuk pemula:

1. **Tentukan Kebutuhan**  
   - **Gaming**: Pilih switch linear (Red, Gateron Milky Yellow) atau tactile (Brown). Layout TKL atau 60% cocok untuk ruang meja lebih luas.
   - **Mengetik (Kantor/Penulis)**: Pilih switch tactile (Brown, Boba U4T) untuk umpan balik nyaman. Full-size atau TKL lebih praktis.
   - **Campuran (Gaming + Mengetik)**: Brown switch atau Gateron Milky Yellow (linear tapi lebih “thocky” dari Red) cocok untukmu, karena kamu kurang suka Red.
   - **Contoh**: Jika kamu lebih suka mengetik dengan umpan balik tapi tidak terlalu berisik, coba keyboard dengan Brown switch atau tactile switch seperti Gateron Ink Black.

2. **Pilih Switch yang Tepat**  
   - **Rekomendasi untukmu**: Hindari Red (linear, “crispy”) dan coba Brown (tactile, ada bump, 45g) atau Gateron Milky Yellow (linear tapi lebih berat dan “thocky”, 50g). Brown lebih seimbang untuk pemula.
   - **Tips**: Beli switch tester jika memungkinkan, atau tanya komunitas (misalnya, di r/MechanicalKeyboards) untuk rekomendasi switch berdasarkan preferensi suara/rasa.
   - **Hot-Swappable**: Pilih keyboard hot-swappable agar bisa ganti switch tanpa solder (contoh: Keychron V5 Max, NuPhy Gem80).

3. **Perhatikan Keycaps**  
   - **Bahan**: Pilih PBT (lebih tahan lama, suara lebih dalam) daripada ABS (licin seiring waktu).  
   - **Profil**: Cherry atau OEM cocok untuk pemula karena nyaman.  
   - **Tips**: Pastikan keycaps double-shot (tulisan tidak mudah pudar) atau dye-sub untuk daya tahan.

4. **Cek Build Quality**  
   - **Case**: Aluminium lebih premium, tapi plastik tebal (seperti Keychron) sudah cukup untuk pemula.  
   - **Stabilizer**: Cari review yang menyebut stabilizer “pre-lubed” atau minimal tidak “rattle”.  
   - **Tips**: Baca ulasan di situs seperti mechanicalkeyboards.com atau tonton review di YouTube.

5. **Pilih Layout yang Sesuai**  
   - **Full-size**: Untuk produktivitas, punya numpad.  
   - **TKL**: Tanpa numpad, lebih compact.  
   - **60%/65%**: Minimalis, cocok untuk estetika, tapi butuh adaptasi karena tidak ada arrow keys.  
   - **Tips**: Untuk pemula, TKL atau full-size lebih praktis kecuali kamu suka estetika minimalis.

6. **Fitur Tambahan**  
   - **Hot-Swappable**: Memungkinkan eksperimen dengan switch tanpa solder.  
   - **Nirkabel**: Bluetooth/2.4GHz untuk fleksibilitas (contoh: Keychron Q1 Max).  
   - **RGB**: Bagus untuk estetika, tapi tidak wajib.  
   - **Software**: Pastikan kompatibel dengan OS-mu (Windows, macOS, Linux). VIA/QMK lebih fleksibel.

7. **Anggaran**  
   - **$50-80**: Keyboard entry-level seperti Keychron C1, Redragon K552. Cocok untuk coba-coba, tapi keycaps/stabilizer mungkin kurang bagus.  
   - **$80-120**: Pilihan terbaik untuk pemula, seperti Keychron V5 Max, NuPhy Air75 V2, atau KBD67 Lite (barebones untuk custom).  
   - **> $120**: Untuk kualitas premium (Keychron Q1 Max, GMK sets), tapi bisa ditunda sampai kamu lebih paham.  
   - **Tips**: Hindari keyboard gaming murah (<$50) dari merek tidak dikenal di e-commerce, karena sering bermasalah.

8. **Baca Review dan Tanya Komunitas**  
   - **Situs**: mechanicalkeyboards.com, switchandclick.com.  
   - **YouTube**: Channel seperti “Switch and Click” atau “Taeha Types”.  
   - **Komunitas**: r/MechanicalKeyboards, Discord server seperti NovelKeys.  
   - **Tips**: Cari thread “budget keyboard” di Reddit untuk rekomendasi terkini.
